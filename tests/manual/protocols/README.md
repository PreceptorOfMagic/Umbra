# KDE mode-control diagnostic protocols

Unmodified protocol XML from KDE plasma-wayland-protocols v1.20.0:
https://invent.kde.org/libraries/plasma-wayland-protocols/-/tree/v1.20.0/src/protocols

Copyright and SPDX license identifiers are retained in each file; MIT-CMU.txt contains the license.
These private desktop protocols can change incompatibly. They are used by the manual diagnostic,
not yet the production host. Generate client-header and private-code with wayland-scanner.
